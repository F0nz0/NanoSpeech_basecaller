To use this bigger prototype model, please download it from this shared link:
https://drive.google.com/open?id=1mEdxGCpT3mnuFfe5XDUBy-ZbE1QsPe2K&usp=drive_fs

The configuration file is already present in this repository with the same root name at:
models/NanoSpeech_RNA004_19classes_12mods_m50M_e164chunk4_trainings_UHRRnativeIVTNativeCellsSynth_FULL_DS_FROM_DISK.h5.cfg

If you want to download it using the terminal you can use the gdown utility following these steps:
1) Install gdown via pip if you don't have it:
pip install gdown

2) move to the models directory:
cd NanoSpeech_basecaller/models

3) download the model using its ID:
gdown "https://drive.google.com/uc?id=1mEdxGCpT3mnuFfe5XDUBy-ZbE1QsPe2K"
